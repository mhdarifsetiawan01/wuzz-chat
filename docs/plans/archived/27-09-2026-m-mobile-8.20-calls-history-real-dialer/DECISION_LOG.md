# DECISION LOG — M-Mobile-8.20

- **DEC-M32 (Local Call Logs Table Schema)**: Menambahkan tabel `local_call_logs` ke database SQLite `wuzzchat.db` dengan WAL mode, multi-tenant isolation via `user_id`, serta indeks teroptimasi `(user_id, created_at DESC)` untuk pagination dan query performa tinggi.
- **DEC-M33 (Single-Invocation Call Log Guard)**: Menerapkan guard ref berbasis key sesi panggilan (`${room}_${direction}_${startTime}`) di `CallContext.tsx` untuk mencegah duplikasi penulisan log ke SQLite akibat race condition antara event penutupan soket/teardown WebRTC lokal dan notifikasi WebSocket remote (`call_end`, `call_reject`).
- **DEC-M34 (Call Initiation Room Auto-Resolution)**: Mendukung fleksibilitas `startCall` agar pemanggil dapat memulai panggilan hanya dengan parameter `peerId`. Jika `roomId` kosong, `CallContext` otomatis memanggil `startDirectChat(peerId)` untuk membuat/mengambil `room_id` resmi dari server sebelum mengirimkan SDP Offer.
- **DEC-M35 (Aurora Dark Mode FAB Dialer & Contact Picker)**: Memanfaatkan primitive `BottomSheetModal` yang telah distandarisasi untuk UI dialer kontak baru, menggabungkan input pencarian debounced dengan daftar kontak direct chat yang sudah ada untuk kemudahan panggilan instan 1-ketukan.
- **DEC-M36 (BottomSheet Soft Keyboard Overflow & Status Bar Clamping)**: Menambahkan `paddingTop: Math.max(insets.top, 24) + spacing.lg` pada `modalRoot` dan membatasi `sheetCard` dengan `maxHeight: '100%'` serta `flexShrink: 1` agar saat keyboard software Android muncul, modal sheet tidak terdorong melebihi batas atas layar (status bar clipping), serta drag handle dan header title tetap terjaga rapi.
